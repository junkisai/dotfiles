# ブラウザ接続

local では package.json / README から起動方法を確認し、プロジェクトが提供するテスト認証またはモックを使う。認証回避を新しく作る前提にはしない。
staging は利用可能な接続ツールでログイン済みセッションを使う。Chrome の既存プロファイルを再起動する固定コマンドを実行しない。

現在の環境が指定するブラウザ操作ツールがあれば、その契約を優先する。Playwright が利用可能な環境では対象のページ・要素を観測して locator を作り、操作後の画面で結果を確認する。

共有セッションでは `browser.close()`、ログアウト、最後のタブを閉じる操作を避ける。書き込み操作は依頼で許可されたテストデータ・操作に限る。実データの映り込みをマスクし、録画でマスクが追従しない区間は含めない。

PR への結果投稿まで依頼されているときは、実際に観測した結果を一時ファイルに書き、`gh pr comment <PR> --body-file <file>` を使う。未実施を成功扱いしない。
