# グラレコ

話題の全体像が分かる PNG と、細部を残した Markdown 台帳を作る。データグラフやスライドの依頼とは区別する。

- 全文を確認し、[台帳の作り方](references/topics.md) に従って話題を拾う。要約だけを素材にして原文の話題を落とさない。
- 話の構造に応じて、因果・時間軸・並列の配置を選ぶ。重要な論点、決定事項、次の行動を見つけやすくし、固定の項目数や配置へ無理に合わせない。
- 絵柄や密度の案が必要なときは [プロンプトの例](references/prompt-template.md) の関連節を参照する。例の配色・座標・件数は調整できる。
- [生成と確認](references/generation.md) に従い、実際の画像と台帳を照合する。既定は16:9横長で可読性を優先し、返された実解像度を報告する。

指定がなければ入力ファイルと同じ場所へ `<名前>-grareco.png` と `<名前>-grareco-topics.md`。貼付テキストなら `~/Downloads/` に内容名と日付で保存する。同名があれば版番号を付ける。

完了時は2つのパス、画像に載った項目数、台帳のみの項目数、残る文字崩れや主な非掲載項目を伝える。画像だけで情報の完全な再現を保証しない。
