# 生成と確認

画像生成には実行環境の imagegen ツールとその制約を使う。同梱 `scripts/generate.sh` は Codex CLI で生成する環境用のラッパーで、直接の imagegen ツールが使えるならそれを優先する。

CLI ラッパーを使う場合:

```bash
<skill-dir>/scripts/generate.sh <prompt.txt> <output.png>
```

終了コード3は認証、4は利用枠、1はその他のエラー。ログを確認し、認証が必要ならユーザーのログイン完了を待つ。ラッパーは16:9に整える際に中央基準で余白を切るため、周辺の文字が欠けていないか確認する。

画像を実際に開き、台帳の掲載予定項目と文字・数字・配置・可読性を照合する。読み取れない箇所は成功扱いしない。欠落・文字崩れの場所を指定して修正する。

生成の既定予算は初回＋修正1回。全体再生成で良い部分が崩れることがあるため、前版と比較して良い方を残す。ユーザーが追加修正を求めた場合はその範囲で続け、予算内で直らなかった箇所は台帳と報告に明記する。
