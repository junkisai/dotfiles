## 網羅の考え方

**このスキルの目標は「見やすいダイジェスト」ではなく「1枚で全部わかる記録」。** 話題を絞って余白のある絵は、その場に居た人の記憶の索引にしかならない。居なかった人が全体を再構成できる状態を狙う。

したがって、**トピック台帳の行は原則すべて絵に載せる**。入りきらないと感じたときの手順は「落とす」ではなく次の順:

1. 箇条書きをグリッド表に変える（同じ面積に2〜3倍入る）
2. セクション内を2カラムに割る
3. 因果を図にして、3〜4行を1つの図にまとめる
4. 文字サイズを3段階に分け、細目を小さい段に落とす
5. セクションを1つ増やす（6〜9の範囲で）

ここまで試して入らない行だけ、台帳に `台帳のみ` と書いて残し、報告で名指しする。

**ただし密度だけを上げても読めない。** 同じ大きさの枠を並べただけの絵は、100項目載っていても目が滑る。密度を可読性に変えるのは、次の3つ:

- **ストーリーの順に置く**（背景 → 現状 → 事例 → 芯 → 打ち手 → 次の一歩）
- **中央の芯を、周囲より明確に大きくする**
- **色を4色に固定し、用途を決める**

密度は**項目数**で稼ぐもので、**1項目の長さ**で稼ぐものではない。生成モデルが日本語を崩すのは、長い文を1つの図形に押し込んだとき。短いフレーズなら 100 個並べても崩れない。

| | 目安 |
|---|---|
| 台帳の行数 | 100〜200（入力量しだいで超えてよい） |
| うち画像に載る行 | 60〜120 |
| セクション数 | 6〜9（番号を振る） |
| 1セクションあたりの項目数 | 8〜15（中央の芯だけ多くてよい） |
| 日本語の総量（画像内） | 800〜1400文字 |
| 1項目あたりの長さ | **4〜14文字**（カード本文・背景説明のみ最大24文字） |
| 人物イラスト | 2〜4箇所 |
| 小アイコン | 項目の半分以上に添える |

長い文が出てきたら、切るのではなく**体言止めに畳む**。「そもそも何から始めればいいか分からない、という問い合わせが一番多いです」→「何から始めるか分からない」。

## 標準レイアウト

**迷ったらこれ。** セクションの位置と役割を固定し、左上から右下へ視線が流れるように置く。

```
 ┌①───────┐  ╔═══ タイトル ═══╗  ┌③─────────────┐
 │ 背景・前提  │  ║   日付・登場人物   ║  │ 象徴的な事例       │
 │ ・項目 ◇    │  ╚═════════════╝  │ ┌────┐┌────┐│
 │ ・項目 ◇    │  ┌②─────────────┐│ │事例1  ││事例2  ││
 └─────────┘  │ 現状の棚卸し（カード横並び）││ └────┘└────┘│
                │ ┌──┐┌──┐┌──┐┌──┐│└───────────────┘
 ┌④━━━━━━━━━━━━━━━━━━━━━━━━━┓ ┌⑤─────────────┐
 ┃  この回の芯（いちばん大きく）           ┃ │ 打ち手・決めたこと    │
 ┃ ┌─A─────┐┌─B─────┐┌─C─────┐┃ │ ☑ 項目             │
 ┃ │ 論点1     ││ 論点2     ││ 論点3     │┃ │ ☑ 項目             │
 ┃ │ ・原因    ││ ・原因    ││ ・原因    │┃ │ ☑ 項目             │
 ┃ │ 「引用」  ││  〔図解〕 ││  〔図解〕 │┃ │ ☑ 項目             │
 ┃ └────────┘└────────┘└────────┘┃ └───────────────┘
 ┗━━━━━━━━━━━━━━━━━━━━━━━━━━━┛ ┌ 次回日程 ┐┌ 締めの一言 ┐
 ┌⑥ ネクストアクション（全幅・担当者と期限つき）─┐└─────────┘└──────────┘
```

| 位置 | 役割 | 中身 |
|---|---|---|
| 最上部中央 | タイトル | 大きな手書き文字。下に小さく日付、さらに小さく登場人物と役割 |
| 左上 ① | 背景・前提 | なぜこの話をしているか、直近で何があったか、感情の状態。**弱めでよい** |
| 上部中央〜右 ② | 現状の棚卸し | 事業・テーマが複数あればカード横並び。1カードに見出し＋2〜4行＋アイコン1つ |
| 上部右 ③ | 象徴的な事例 | エピソードカード1〜2件。抽象論だけでは伝わらないときに効く |
| **中央 ④** | **この回の芯** | **画面の3〜4割。論点が3つなら A/B/C の3カラム。引用と図解をここに置く** |
| 右 ⑤ | 打ち手・決めたこと | チェックリスト。可能なら ④ の論点と対応づけて並べる |
| 最下部 全幅 ⑥ | ネクストアクション | 「誰：いつ 何を」を矢印でつなぐ |
| 右下 | 次回日程 / 締めの一言 | 日程はカレンダー風の独立ボックス、締めは雲形の吹き出し |

置き方の原則:

- **中央だけ別格に大きく取る。** 他のセクションと同じ大きさで描かれたら、それは失敗。プロンプトに「いちばん大きく」「周囲より広く」と明記する
- **問題 → 打ち手の対応を見せる。** ④の右に⑤を置き、対応する項目を同じ順に並べる
- **背景（①）は情報を詰めない。** ここが重いと、読み手は中央にたどり着く前に疲れる
- **ネクストアクションには担当者と期限を入れる。** 「①LINE配信」ではなく「かなえ：8/25 LINE配信」
- **締めの一言は、会話全体を一文で表せるときだけ置く。** 強引に名言を作らない

## 別の構図パターン

標準レイアウトが合わないときだけ切り替える。

### 時間軸型

画面下部に太い横線を1本引き、その上に出来事を左から右へ並べる。上側に各時点の詳細セクションをぶら下げる。「最初はこう思っていたが、話すうちに変わった」という転換がある対談・ふりかえりに合う。転換点に星や電球を置く。

### 島型

大小の囲み（島）を非対称に散らし、関係のあるものだけを線でつなぐ。論点が並列で順序がないブレスト回に合う。島ごとに番号は振らず、色分けだけで区別する。

### 中央放射型

中央に大きくテーマを置き、周囲に6〜8個のセクションを放射状に配置する。1つの問いを多角的に掘った回に。中央に置く一語が決まっているときだけ選ぶ。

## 因果を図にする

**文章で説明できることでも、構造を絵で説明できるなら絵にする。** 箇条書き3〜4行が1つの図になり、面積が減って理解が速くなる。1枚に2〜3箇所入れると効く。全部を図にすると、かえって読めなくなる。

### 2者の関係（依存・対立・すれ違い）

```
人物2人を鎖でつなぐ。上に「“頼られている私” に幸福感」
その下に矢印を1本下ろし、鎖がほどけて2人が離れる絵を小さく描く。
横に「離れる＝自走できた証」
```

依存・共依存・執着・すれ違いはこの型で描く。鎖のほかに、絡んだ糸、引っ張り合う矢印も使える。

### 絞り込み（集客・選抜・離脱）

```
漏斗（じょうご）の形に3段の箱を縦に並べ、下ほど狭くする：
「発信（ストーリー／リール）」→「詳細希望」→「Zoom資料」
漏斗の下に小さく「…で終わっていた」
漏斗の右に赤い囲みで「不足：疑似体験・小さな成功体験」
```

導線・ファネル・歩留まりはこの型。どこで細くなっているかが一目で分かる。

### 悪循環

```
4つの短い箱を時計回りに置き、矢印で輪にする：
「無料で提供」→「自信が持てない」→「仕事を足す」→「疲弊」→（最初に戻る）
輪の中央に「？」やもやもやの記号を置く
```

抜け出せない構造を描くときに使う。矢印が閉じていることが意味を持つ。

### 連鎖（原因 → 状態 → 結果）

```
縦に3〜4段、下向き矢印でつなぐ：
「過去の施術トラブル」↓「自信の低下」↓「無料提供」↓「仕事が増え続ける」
```

因果を追ってほしいときに。横に流すより縦のほうが「積み上がった感」が出る。

### Before / After

```
枠の中を左右に分け、左に「BEFORE」、右に「AFTER」の小さなラベル。
左に困った表情の人物と項目を縦に、右に笑顔の人物と項目を縦に。
その間に大きな右向き矢印を1本。
```

変化の事例を見せるときの定番。人物の表情で変化を語らせる。

## 色の使い方

**アクセントカラーは4色まで。用途を固定する。** セクションごとに色を変えると、色が意味を持たなくなり、密度が高いほど散らかって見える。

| 色 | 用途 |
|---|---|
| オレンジ | 重要な論点・強調・チェックマーク |
| ティール（青緑） | 現状・事実・アクション |
| ピンク | 感情・人間関係・締めの一言 |
| イエロー | 気づき・マーカー・中央の芯の下敷き |

- **背景は白**（またはごく薄いアイボリー）。情報密度が高いので、背景に模様を入れない
- **線は黒でやや太め**。手描きの柔らかさは残す
- **中央の芯だけ、文字自体を色で塗り分けてよい**。「世界観 ＝ 何屋さん × キャラクター」を赤・青・紫にするなど。ここに視線が最初に落ちる
- 枠線の色はセクションごとに変えてよいが、**4色の範囲内で回す**。5色目・6色目を足さない

## 1枚に全部入れる詰め方

台帳の行が入りきらないと感じたら、落とす前にこの4つを順に試す。

### 1. グリッド表にする

分類・一覧・比較は必ず表にする。縦の箇条書きで1セクション埋まる量が、4行3列の表なら同じ面積に**全12件＋各マスのアイコン**まで入る。

```
【③：右上、緑の枠】
4行3列の表。各マスに番号・名前・キーワード・小アイコンを入れる：
「①〈名前〉／〈キーワード〉」「②〈名前〉／〈キーワード〉」…
（全12マス分を一字一句列挙する）
```

### 2. セクション内を2カラムに割る

1セクションに10項目以上あるときは、枠の中を縦線で左右に割る。プロンプトで明示する。

```
枠の中を縦の細線で左右2列に分ける。
左列に上から：「〈項目〉」「〈項目〉」「〈項目〉」「〈項目〉」
右列に上から：「〈項目〉」「〈項目〉」「〈項目〉」「〈項目〉」
```

### 3. 因果を図にまとめる

上の「因果を図にする」を使う。箇条書き3〜4行が図1つになるので、行数が減って面積も空く。

### 4. 文字サイズを3段階に分ける

すべてを同じ大きさで描くと入らない。重要度で3段に分け、プロンプトで名指しする。

| 段 | 使う対象 | プロンプトでの言い方 |
|---|---|---|
| 大 | タイトル・中央の芯・いちばん大きい数字 | 「極太の手書き文字で」 |
| 中 | セクション見出し・決定事項・ネクストアクション | 「読みやすい太さの手書き文字で」 |
| 小 | 補足・注意・細目・出典 | 「小さめの手書き文字で詰めて」 |

**小の段に落としてよいのは、単体で意味が通る細目だけ**。中央の芯を小さくしない。

## 視覚部品カタログ

グラレコらしさは、テキストを「ただの箱」ではなく意味に合った図形に載せ、**小アイコンを添える**ことで出る。プロンプトでは図形もアイコンも名指しする。台帳の「種別」列から引く。

| 台帳の種別 | 図形 | プロンプトでの言い方 |
|---|---|---|
| （タイトル） | 大きな手書き文字（囲みなしでも可） | 「画面最上部中央に極太の手書き文字で」 |
| 背景 | 小アイコン付きの行、人物イラスト | 「各行の頭に小アイコンを添えて、小さめの文字で」 |
| 現状 | カード横並び | 「見出し・2〜4行・アイコン1つを1組にしたカードを4枚横並び」 |
| 課題・原因 | 図解（鎖・漏斗・輪・縦の矢印） | 「因果を図にする」の型から選ぶ |
| 気づき | 極太のカラー文字＋マーカー | 「黄色いマーカーを引いた極太文字で」 |
| 定義 | 極太のカラー文字＋記号 | 「『世界観』を赤、『何屋さん』を青、『キャラクター』を紫の極太文字で」 |
| 数字 | 数字を大きく、単位を小さく | 「大きな手書き数字で60%、その左に項目名」 |
| 分類 | グリッド表 | 「4行3列の表。各マスに番号・名前・キーワード・小アイコン」 |
| 手順 | 番号つき箱＋右向き矢印 | 「①②③の箱を矢印でつなぐ。各箱に小アイコン」 |
| 事例 | エピソードカード（人物＋見出し＋2〜3行） | 「人物イラスト・見出し・3行を1組にしたカードを2枚縦に」 |
| 発言 | 吹き出し（人物の隣） | 「人物イラストの隣に吹き出しで」 |
| 決定 | チェックリスト | 「オレンジのチェックマークを頭につけた行を5つ」 |
| 宿題 | 全幅の横帯＋矢印フロー | 「最下部に全幅の帯。5つの項目を右向き三角でつなぐ」 |
| （次回日程） | カレンダー風の独立ボックス | 「右下にカレンダーの絵と、大きな文字で日付・時刻」 |
| （締めの一言） | 装飾つきの雲形吹き出し | 「右下に雲形の吹き出し、まわりにキラキラ」 |
| （人・チーム） | やわらかい線画の人物（顔つき・髪色つき） | 「にこやかな女性のイラスト、色鉛筆風」 |

アイコンの例: カレンダー / 時計 / スマホ / LINE / 店舗 / カメラ / プレゼント / トロフィー / 目 / 耳 / 吹き出し / 本 / 鎖 / 漏斗 / 王冠 / パレット / ハート / 電球 / 虫めがね / 鉛筆 / グラフ / 警告 / チェックマーク / 足 / 食事 / ノート

人物イラストは 2〜4箇所。棒人間ではなく、色鉛筆で描いたような柔らかい人物にする。表情で「不安・悩み・安堵・発見・自信・喜び」を出す。

**センシティブな話題の描き方。** メンタル・健康・人間関係の悩みを描くときは、泣き顔や病的な描写を避け、**疲れている人物・もやもやの記号・小さな雨雲**に留める。当事者が見返すファイルであることを忘れない。

## プロンプトテンプレート

以下をコピーして 【】 の中身を差し替える。スクラッチパッドに `prompt.txt` として書き出し、`scripts/generate.sh` に渡す。

冒頭の絵柄・可読性指定と末尾の禁止事項は毎回そのまま使う。ここを削ると密度が落ちたり、頼んでいない文字が混ざったりする。

セクション数・各セクションの項目数は割り付けに合わせて増減する。**セクション番号を振った台帳の行が、全部このプロンプトに現れているか、書き終えたら数える。**

```
情報が整理された手描き風グラフィックレコーディング（グラレコ）を1枚生成してください。
サイズは16:9横長、1920x1080ピクセル。できるだけ高い解像度で、細部までくっきり描いてください。

【絵柄】
白い紙に色鉛筆と水彩マーカーで描いた雰囲気。細めの黒い輪郭線、やわらかい配色。
アクセントカラーはオレンジ・ティール（青緑）・ピンク・イエローの4色に抑える。
オレンジは重要な論点、ティールは現状とアクション、ピンクは感情と人間関係、
イエローは気づきとマーカーに使う。5色目を足さないこと。
読みやすい丸みのある手書き文字。セクションごとに角丸の枠で囲む。
人物は色鉛筆風のやわらかい線画で、表情がわかるように描く。
背景は不透明な白で、画面の隅々まで塗りつぶす。透明・透過の背景にはしないこと。
雰囲気は、客観的に整理されているが人間味がある日本のグラフィックレコーディング。
子供向け教材のように幼くせず、企業資料のように無機質にもしないこと。

【キャンバスの使い方】
指定した 1920x1080 のキャンバス全体を使い切ってください。
左右や上下に、何も描かれていない白い帯を残さないこと。
絵を中央に小さくまとめて周囲を余白にするのではなく、
セクションを画面の端まで広げて、隅々まで配置してください。

【文字の強弱】
文字は4段階に描き分ける。
1. タイトル：いちばん大きく、極太
2. 中央④の結論：極太のカラー文字。まわりを広く空ける
3. セクション見出し・決定事項・ネクストアクション：読みやすい太さ
4. 補足・細目：やや小さめ
本文が読める大きさを下回らないようにする。

【日本語の可読性】
highly legible Japanese text, clean Japanese handwritten-style lettering,
excellent readability, large enough text, avoid tiny text,
correct Japanese characters, clear section headers.

【タイトル：画面最上部中央】
極太の手書き文字で「〈タイトル 10〜20文字〉」
その下に小さく「〈日付〉 グラレコ」
さらに下に小さく「〈登場人物と役割〉」

【①：左上、背景。控えめな枠】
丸の中に①の番号バッジ、その右に見出しを描く：「背景」
各行の頭に小アイコンを添えて、小さめの文字で：
「〈項目 4〜24文字〉」（〈アイコン〉）
「〈項目 4〜24文字〉」（〈アイコン〉）

（全カード分を一字一句列挙する）

【③：右上、象徴的な事例】
丸の中に③の番号バッジ、その右に見出しを描く：「〈見出し〉」

「①〈事例の要点〉」＋「〈行〉」「〈行〉」

【④：画面中央、いちばん大きく。画面の3〜4割を使う】
丸の中に④の番号バッジ、その右に見出しを描く：「〈この回の芯〉」
枠の中を縦線で3つに割り、それぞれ A / B / C のラベルを付ける。

A の列：見出し「論点1：〈見出し〉」
「〈項目 4〜14文字〉」「〈項目〉」「〈項目〉」
下にオレンジの囲みで引用「〈本人の発言 15〜30文字〉」

B の列：見出し「論点2：〈見出し〉」
「〈項目〉」「〈項目〉」「〈項目〉」
〈「因果を図にする」から選んだ図の指定をここに書く〉

C の列：見出し「論点3：〈見出し〉」
〈同上〉

【⑤：右、打ち手・決めたこと】
丸の中に⑤の番号バッジ、その右に見出しを描く：「打ち手・合意したこと」
オレンジのチェックマーク付きで、各行に小アイコンを添えて：
「〈打ち手 8〜20文字〉」（〈アイコン〉）
（全件を一字一句列挙する）

【⑥：最下部の全幅の帯】
丸の中に⑥の番号バッジ、その右に見出しを描く：「ネクストアクション」
項目を右向き三角でつなぐ。各項目に小アイコンと担当者名：
「〈担当者〉：〈期限〉 〈行動 8〜16文字〉」（〈アイコン〉）

【右下：次回日程と締めの一言】
カレンダーの絵と、大きな文字で「〈次回の日付〉」「〈時刻〉」
その右に雲形の吹き出しで「〈締めの一言 20〜40文字〉」

【余白と配置】
ここでいう余白は枠と枠の「あいだ」のこと。画面の外周に帯を残すことではない。
セクション同士を接触させず、枠と枠の間に隙間を空ける。
各枠の内側にも余白を残し、文字が枠線に触れないようにする。
④の枠は他のどのセクションよりも明確に大きく描く。
視線が左上から右下へ流れるように配置する。
上に列挙したテキストは1つも省略せず、すべて画面内に描く。
空いたところに文字や図形を勝手に足して埋めないこと。

日本語のテキストはすべて上記の通り一字一句正確に描画してください。
誤字・崩れた文字・意味不明な文字を作らないでください。
上記に書いていない文字（英字を含む）を勝手に足さないでください。
```

英単語は【】の中に書いたものだけ描かれる。固有名詞（Pinterest、Instagram など）は
英字のまま書いてよいが、書いていない英字が出てきたら Step 8 で直す。
A / B / C や BEFORE / AFTER を使うときは、末尾に「〜以外の英字は描かないでください」と添える。

**背景の白は絵柄指定と `generate.sh` の二重で守っている。** 指定を書いても生成側がアルファ付きの
PNG を返してくることがあり、紙の白い部分が透明で抜ける。Read で開くぶんには白く見えるので、
目視では気づけない。スクリプトが最後に白を敷いて RGB に落とすので、絵柄指定のこの1行は
消さずに残す ―― 生成側が最初から不透明で描いてくれるほうが、色の縁が濁らない。

## 修正・追加用プロンプト

### 抜けを足すとき

**ファイル名を明示して読み込ませる。** `generate.sh` は毎回新しい codex セッションを立てるので、
生成側は前回の画像を覚えていない。ただし保存先ディレクトリで動くため、ファイル名を書けば読める。
「生成した画像の」と書くだけでは何も参照されず、まっさらな絵が返ってくる。

```
同じフォルダにある既存の画像ファイル
「〈PNGのファイル名〉」
を読み込み、次の1箇所だけを修正した画像を作ってください。

修正箇所：〈場所（例: ⑤右のオレンジの枠）〉の項目が抜けています。
そこに次のテキストを、既存の項目と同じ体裁・同じ文字サイズで追加してください：
「〈抜けたテキスト〉」「〈抜けたテキスト〉」

それ以外の要素・文字・配置・色・絵柄・レイアウトはいっさい変えないでください。
既にある項目を1つも消したり増やしたりしないでください。
```

### 崩れを直すとき

```
同じフォルダにある既存の画像ファイル
「〈PNGのファイル名〉」
を読み込み、次の1箇所だけを修正した画像を作ってください。

修正箇所：〈場所〉の文字が「〈崩れて描かれた内容〉」になっています。
ここを正しく「〈正しいテキスト〉」と描き直してください。
〈色の塗り分けなど、その箇所で保ちたい指定〉はそのままにしてください。

それ以外の要素・文字・配置・色・絵柄・レイアウトはいっさい変えないでください。
既にある項目を1つも消したり増やしたりしないでください。
```

出力先は元の PNG を上書きせず `-v2`、`-v3` と足す。直したつもりが別の箇所を崩していたとき、
前の版と見比べられないと判断できなくなる。

密度が高いぶん崩れる箇所は増える。**3箇所までは1回のプロンプトでまとめて名指ししてよい**。
それ以上あるときは、影響の大きい順に3つずつ。

### 修正は1回で止める

**この追加プロンプトは、既存画像の1箇所を編集しているのではない。** 生成側は元の画像を見ながら
全体を描き直している。だから2回目を撃つと、1回目で直った箇所が崩れ直す確率のほうが高い。

実際の例 ―― 3箇所（擬態語の崩れ・「目次」が「図式」・「ペース」が「ベース」）をまとめて名指しした
1回目で2箇所が直り、残り1箇所を言い換えて2回目を撃ったところ、その1箇所は直ったが、
1回目で直っていた「ペースメーカー」が「ベースメーカー」に戻った。

だから:

- **修正プロンプトは1回だけ撃つ**。撃ったら結果を照合し、そこで打ち止めにする
- **2回目の結果が1回目より悪ければ、前の版を採用する**。新しいほうが良いとは限らない
- **どの版を採るかは、崩れの「数」ではなく「実害」で決める**。意味が変わる誤り（「ペース」→「ベース」）は、
  文脈で読める崩れ（擬態語が1文字ずれる）より重い
- 修正版では、直した箇所に消し跡のような小さな汚れが残ることがある。読める範囲なら追わない

2回撃っても残る崩れは、その語自体が崩れやすい。台帳側の表記を短く言い換えるか、ひらがなに開いて、
**次に作り直すときに反映する**。同じ絵で粘らない。

## 記入例

### 例1：コンサル回（標準レイアウト・ストーリー型）

92分の個別コンサル。「1ヶ月半連絡が途絶えていた」ところから始まり、共依存の構造という芯にたどり着いた回。

```
【タイトル】「かなえさん個別コンサル」／小さく「2026/08/24 グラレコ」
        さらに小さく「かなえ（受講者・ダイエットサポート／サロン経営） × ぴんりこ（コーチ）」
【①背景】左上・アイコン付き6行＋吹き出し
        カレンダー「月2回×6ヶ月の継続セッション」／ 時計「前回から約1ヶ月半あいた」
        親子「子育てで手いっぱい」／ もやもや「クセのあるクライアント対応が続き、メンタルダウン」
        吹き出し「"連絡がほしかった"と本音を共有」／ 握手「今後は"ちょいちょいつつく"で合意」
        人物2人＋吹き出し「本音で話せてスッキリしました〜」
【②現状の棚卸し】上部中央・カード4枚横並び
        「サロン」7月は10数名来店／売上20万円／売っぱは全員無料モニター（店舗アイコン）
        「90デイズ1期」ほぼ無料招待 有料は2名／場の雰囲気はよい（人物3人）
        「個別ダイエットサポート」いちばん自信がある柱／新規が伸び悩み（力こぶ）
        「インスタ」リールが伸びてきた手応えあり（スマホ）
【③しんどかったクライアント】右上・エピソードカード2枚
        「① 目標-3kgに届かず"納得いかない" → 最終セッション拒否 → 話し合い後、アフターフォローへ」
        「② 200g増で"太った"と反応、LINE攻撃、グループ離脱希望」
【④3つの論点】中央・最大・A/B/Cの3カラム
        A「論点1：売ることへのブロック」
          ・ダイエットサポートにはブロックがない ・骨盤矯正への自信のなさが足を引っ張る
          ・過去の施術トラブルが影響 ・サロンをうまくできなかった"未達成感"
          オレンジ囲みの引用「"私自体に価値がない。やってあげて初めて価値が出る"」
          →「その結果、足し算で仕事が増え続ける」
        B「論点2：共依存の構造」＋〔鎖の図解〕
          ・"頼られている私"に幸福感 ・お互いが執着し合う鏡の関係
          ・ぴんりこへのモヤモヤにも同じ構造 ・根本が変わらないと執着タイプを呼び寄せる
          鎖がほどける絵＋✓「離れる＝自走できた証」✓「空いたキャパに、今の自分にフィットする人が来る」
        C「論点3：90デイズ1期が集まらなかった理由」＋〔漏斗の図解〕
          漏斗「発信（ストーリー／リール）」→「詳細希望」→「Zoom資料」＋「で終わっていた…」
          ・集客は4〜5ヶ月前の発信の結果 ・販売動線が弱い
          ・不足していたのは 赤囲み「疑似体験・小さな成功体験」
【⑤打ち手・合意したこと】右・チェック10行＋アイコン
        ☑「足つぼの無料提供を今日で終了 → 9月から有料化」
        ✉「8/25 公式LINEでキャンペーン配信」
        🎁「募集の前段に"チョコパフェ"的なワークショップを置く」…
【⑥ネクストアクション】最下部・全幅・担当者と期限つき
        「かなえ：8/25 足つぼキャンペーンを公式LINEで配信」
        「かなえ：9月に向けて、前段ワークショップを設計」
        「ぴんりこ：1ヶ月に1回、ちょいちょい声かけ」
【右下】カレンダー「9/25（金）14:00〜15:30」
        雲形の吹き出し「頼られたい気持ちは、弱さではなく強み。
        ただし"依存"ではなく"自走を増やす支援"に変えていく」
```

効いている点:

- **ストーリーの順に置いている**。背景 → 現状 → 事例 → 芯 → 打ち手 → 次の一歩。左上から右下へ読める
- **中央だけ別格に大きい**。3論点を A/B/C の3カラムにして画面の4割弱を使っている。ここが芯だと一目で分かる
- **論点2と3を図にした**。共依存は鎖、集客は漏斗。箇条書き4行ぶんが図1つに収まり、しかも速く伝わる
- **引用を吹き出しではなく囲みで強調している**。「私自体に価値がない」は本人の認知構造そのものなので、箇条書きに混ぜず独立させた
- **ネクストアクションに担当者と期限が入っている**。誰が何をいつまでにが1行で読める
- **締めの一言が会話全体を要約している**。名言を作ったのではなく、話の結論をそのまま一文にした

### 例2：講座回（分類が主役）

2時間16分・約45,000字の講座文字起こしを、台帳 148 行に起こし、うち 96 行を8セクションに割り付けた実例。分類・一覧が主役なので、中央に定義、右上にグリッド表を置いた。

```
【タイトル】「Myブランドの学校 8月後半 授業DAY」
        サブ帯「ブランドアーキタイプで世界観をつくる」／ 小さく「ぴんりこ × ゆきちゃん」
【①冒頭の連絡】赤枠・アイコン付き5行
        カレンダー「9/12 東京オフ会」＋囲みで「申込締切 8/21（金）」
        カメラ「アーキタイプを使った撮影＆チーム制作」ほか
【②世界観とは？】中央・最大・雲形
        極太カラー文字「世界観 ＝ 何屋さん × キャラクター」
        下に「世界観 ≠ 職業」「同業者っぽさだけで作らない」
        目・耳・吹き出しアイコンで「視覚55%」「聴覚38%」「言語7%」
        人物＋吹き出し「表現は"自分の個性が相手に伝わる形で表現する思いやり"」
【③4ゾーン・12タイプ】右上・4行3列の表
        行見出し「安定・秩序（支える）」「自分・進化（変える）」
                「関係・つながり（つながる）」「創造・表現（生み出す）」
        全12マスに「①イノセント／純粋」〜「⑫統治者／品格・信頼」＋各アイコン
【④自己分析のやり方】3ステップ＋チェック3つ
        「①12タイプを5点満点で直感採点」→「②上位2〜3個に絞る」→「③仮定義して表現を試す」
【⑤ぴんりこさんの例】左下・人物イラスト＋内訳
        「道化師 60%」「探検家 30%」「魔術師 10%」
【⑥事例】カード3枚 ／【⑦実践ヒント】オレンジ・2列・チェック付き
【⑧ネクストアクション】最下部・全幅の帯
        右端の吹き出し「自分らしい世界観で楽しく発信して、一緒に育てていこうね！」
```

効いている点:

- **12分類を表にした**。縦の箇条書きなら1セクション埋まるところが、表なら同じ面積に全12件とアイコンまで入る
- **中央の公式だけ色を変えている**。赤・青・紫に塗り分けると、情報量が多くても視線がまずここに落ちる
- **数字を素材のまま残している**。55/38/7%、60/30/10%、8/21、3〜6ヶ月。絵が雰囲気ではなく記録として機能する

台帳側には、この絵に載らなかった 52 行 ―― 各タイプの詳しい説明、質疑応答のやりとり、
受講生からの相談内容、脱線した雑談 ―― が `〔台帳のみ〕` として残っている。
