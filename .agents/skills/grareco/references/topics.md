# トピック台帳

入力の全文から、話題・論点・具体例・数字・決定・宿題を拾う。元テキストが長い場合は分割して読み、範囲を記録して抜けを防ぐ。

作業表は `# / 画像用の短い表記 / 詳細 / 種別 / 配置先`。同じ主張の反復だけを統合し、異なる数字や具体例は残す。画像用表記は短く、畳んだ内容は詳細へ残す。確信のない人名は「表記要確認」、本人の発言にない引用は作らない。

配置先は全行に記録し、画像へ入らない細部は「台帳のみ」とする。話題・決定・宿題を優先し、文字を詰めすぎて読めない場合は項目のまとめ方を見直す。

納品用 Markdown は画像のセクションに対応させ、項目ごとに `〔画像掲載〕` / `〔台帳のみ〕` と詳細を残す。画像を確認してから掲載扱いを確定し、未確認は未確認と記す。末尾に総数・画像掲載数・台帳のみの数を記す。
