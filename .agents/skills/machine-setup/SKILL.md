# Mac セットアップ

Brewfile と `docs/setup.md` を実態に合わせ、移行に必要な作業を完了する。

- 現行マシンの棚卸しは [audit](references/audit.md)、新しいマシンでの設定は [install](references/install.md) を読む。依頼からモードが分かる場合は確認を繰り返さない。
- スクリプトはこのスキルのディレクトリを基準に実行する。Homebrew 導入等のブートストラップが未了なら、リポジトリの README に従って必要な部分から進める。
- 未インストール項目があることだけで Brewfile から削除しない。移行対象か不明な項目だけ確認し、孤児候補を自動削除しない。
- 配布元と cask は実在を確認する。設定配置の正本は `docs/setup.md` とし、配置一覧をスキルへ複製しない。

完了時は反映した項目、確認結果、ユーザーの認証等を待つ項目を伝える。`brew bundle check` の不足パッケージとファイル構文エラーは区別する。PR 作成は依頼に含まれる場合に行う。
