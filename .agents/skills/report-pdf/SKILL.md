# 社外向けの報告資料 PDF

冒頭で結論が分かり、数字を表と図で確かめられる A4 縦の報告書を作る。HTML と印刷用の CSS で組み、図は SVG で描き、Chrome で PDF にする。Claude Docs や Artifact の書き出しは使わない。Web ページの見た目のまま社外に出てしまうため。

## 組み立て

- 中身を先に固める。章ごとに結論の一文を決め、比べる項目が多いものは表、大小・増え方・内訳は図にする。結論の数字は、冒頭の要約に 4 つまでのカードで並べる。
- [ひな形](assets/template.html) をコピーして書き始める。表紙、要約のカード、表、図、提案の囲み、※の注記、式の囲み、塗り分けた早見表、画面の画像の 2 枚並べ、件ごとの状態の札がそろっている。
- 色はひな形の `:root` のパレットだけを使う。部品は役割の色（`--text`・`--emphasis-text` など）を、図はクラス（`c-hl`・`c-muted` など）を使い、色を直書きしない。目立たせる色は主色（primary）の 1 系統にし、注記の※だけ `--caution-text` にする。
- 図は [図の描き方](references/charts.md) に従って描く。
- 章は `h2.pb` で改ページし、表や図がページをまたがないようにする。書名とページ番号は `@page` で出すので、`@top-right` の書名を資料の題に合わせる。

## 画面の画像

- 見せたい 2〜3 件だけに切り抜き、ステータスバー・タブバー・開発用の表示（デバッグのボタンなど）を外す。JPEG にし、長い辺を 900px に縮める。
- 直す前と直したあとは、同じ項目を同じ位置で撮り、`.pair` で並べる。スマホの縦長の画面は 1 枚 50〜60mm にする。段の幅いっぱいに置くと高さが 10cm を超え、すぐ後ろの表を次のページへ押し出す。横長の画面は段の幅で 1 枚にする。
- 同じ章に表と画像があるときは、表を先に置き、見出し・表・注記を `.keep` で 1 つの塊にする。ページに収まらないときに送られるのが画像だけになり、表が行の途中で分かれない。
- 元の HTML と画像は作業用のフォルダに置き、`src` は HTML からの相対パスで書く。build.sh が埋め込む。

## 文章

- です・ます調で書く。社内の作業メモ（確認事項のチェックリスト、メンション、関数名・ファイルパス・内部の ID）は入れない。
- 実測と推定を分け、前提（規模・為替・単価を確かめた日）を表にする。外から取った単価や仕様は、出典の URL と確かめた日を末尾に載せる。
- 画面の画像の出どころを、確かめ方の囲みに書く。本番そのものではない画面（確認用の環境や、写したデータで撮ったもの）と、先方からもらった画像は、そうと分かるように書く。読み手が本番の画面と取り違えないようにするため。
- 同じ数字が要約・本文・表・例に何度も出る。1 つを直したら HTML の中を検索し、合計や例の計算も含めて全部をそろえる。

## PDF にして確かめる

```sh
bash <skill>/scripts/build.sh <資料>.html [<出力>.pdf]
```

- 出力の既定は、HTML と同じ場所・同じ名前の `.pdf`。ページ数、全ページを PNG にしたフォルダ、ページごとに本文がどこまで下にあるか（fill）を出す。Google Chrome と poppler（`pdfinfo`・`pdftoppm`・`pdftotext`）が要る。
- 出力の PDF を元の HTML と別の場所にすると、同じ名前の `.html` に、画像を埋め込んだ渡す HTML も書く。
- 「確かめる:」と出たページは、本文が上から 55% に届かずに終わっている。章の終わりでなければ、表や画像の塊、または 1〜2 行が次のページへ送られている。
- 全ページの画像を実際に見て、次があれば直して作り直す。
  - 見出しやリード文だけがページ末に残る、1〜2 行だけが次のページに送られる、表や図がページをまたぐ
  - 要約のカードの数字が折り返す
  - 図の数字が棒や隣の数字に触れる（図のあるページは拡大して見る）

## 渡すとき

PDF と渡す HTML を同じ名前で並べて置く（例：`<題>_<YYYYMMDD>.pdf` と `.html`）。build.sh の出力の PDF をその場所にすれば、両方がそろう。置き場所の指定が無ければ `~/Downloads/` にする。直すときは作業用のフォルダの HTML を直して作り直す。

報告では、PDF のパスとページ数、確かめたこと、推定のまま残っている数字を伝える。
