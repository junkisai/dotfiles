# 社外向けの報告資料 PDF

先方が読んで判断できる A4 縦の報告書を作る。HTML と印刷用の CSS で組み、図は SVG で描き、Chrome で PDF にする。Claude Docs や Artifact の書き出しは使わない。Web ページの見た目のまま社外に出てしまうため。

## 構成と見た目は一から決める

決まった雛形はない。誰が読み、何を判断するための資料かから考え、章立て・見せ方・部品・色を資料ごとに決める。前に作った資料の形をなぞらない。

- 読み手が最初の 1 ページで結論をつかめるようにする。先頭に何を置くか（数字・提案・お願い・経緯）は中身で決める。
- 見せ方は中身で選ぶ。比べる項目が多いものは表、大小・増え方・内訳は図、計算の決まりは式、と中身に合う形にする。部品は要る分だけ作り、使わない部品を並べない。
- 色は `:root` の変数にまとめ、部品も図もその変数を使う。目立たせる色は 1 系統にし、読み落とされたくない注記だけ別の色にする。先方や案件のブランドの色が分かっていれば、それに合わせる。
- 印刷用に、背景色を出す `print-color-adjust: exact`、日本語のフォントの指定（Hiragino Sans など）、数字の桁をそろえる `tabular-nums` を入れる。2 ページ以上になるなら、ページ番号を `@page` で入れる。
- 改ページは中身で決める。表・図・囲みには `break-inside: avoid`、見出しには `break-after: avoid` を付け、ページをまたがせない。
- 図は [図の描き方](references/charts.md) を読んでから描く。

## 画面の画像

- 見せたい 2〜3 件だけに切り抜き、ステータスバー・タブバー・開発用の表示（デバッグのボタンなど）を外す。JPEG にし、長い辺を 900px に縮める。
- 直す前と直したあとは、同じ項目を同じ位置で撮り、横に並べる。スマホの縦長の画面は 1 枚 50〜60mm にする。段の幅いっぱいに置くと高さが 10cm を超え、すぐ後ろの表を次のページへ押し出す。横長の画面は段の幅で 1 枚にする。
- 同じ章に表と画像があるときは、表を先に置き、見出し・表・注記を `break-inside: avoid` の 1 つの塊にする。ページに収まらないときに送られるのが画像だけになり、表が行の途中で分かれない。
- 元の HTML と画像は作業用のフォルダに置き、`src` は HTML からの相対パスで書く。build.sh が埋め込む。

## 文章

- です・ます調で書く。社内の作業メモ（確認事項のチェックリスト、メンション、関数名・ファイルパス・内部の ID）は入れない。
- 実測と推定を分け、前提（規模・為替・単価を確かめた日）を読み手が確かめられるようにする。外から取った単価や仕様は、出典の URL と確かめた日を載せる。
- 画面の画像の出どころを書く。本番そのものではない画面（確認用の環境や、写したデータで撮ったもの）と、先方からもらった画像は、そうと分かるように書く。読み手が本番の画面と取り違えないようにするため。
- 同じ数字が冒頭・本文・表・例に何度も出る。1 つを直したら HTML の中を検索し、合計や例の計算も含めて全部をそろえる。

## PDF にして確かめる

```sh
bash <skill>/scripts/build.sh <資料>.html [<出力>.pdf]
```

- 出力の既定は、HTML と同じ場所・同じ名前の `.pdf`。ページ数、全ページを PNG にしたフォルダ、ページごとに本文がどこまで下にあるか（fill）を出す。Google Chrome と poppler（`pdfinfo`・`pdftoppm`・`pdftotext`）が要る。
- fill は、資料の `@page` の `margin`（または `margin-top`・`margin-bottom`）を mm で読み、その内側を本文として測る。mm で読めないときは上 20mm・下 18mm とみなして知らせる。
- 出力の PDF を元の HTML と別の場所にすると、同じ名前の `.html` に、画像を埋め込んだ渡す HTML も書く。
- 「確かめる:」と出たページは、本文が上から 55% に届かずに終わっている。章の終わりでなければ、表や画像の塊、または 1〜2 行が次のページへ送られている。
- 全ページの画像を実際に見て、次があれば直して作り直す。
  - 見出しやリード文だけがページ末に残る、1〜2 行だけが次のページに送られる、表や図がページをまたぐ
  - 大きく出した数字が折り返す
  - 図の数字が棒や隣の数字に触れる（図のあるページは拡大して見る）

## 渡すとき

PDF と渡す HTML を同じ名前で並べて置く（例：`<題>_<YYYYMMDD>.pdf` と `.html`）。build.sh の出力の PDF をその場所にすれば、両方がそろう。置き場所の指定が無ければ `~/Downloads/` にする。直すときは作業用のフォルダの HTML を直して作り直す。

報告では、PDF のパスとページ数、確かめたこと、推定のまま残っている数字を伝える。
