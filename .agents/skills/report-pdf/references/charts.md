# 図の描き方

図は SVG を HTML に直接書く。グラフのライブラリは使わない。図ごとに「何を見せるか」を一文で決め、それを図の題にする（例：「処理時間の 7 割は項目 A」）。

## 形の選び方

| 見せたいこと | 形 |
| --- | --- |
| 項目ごとの大小・内訳 | 横棒。ラベルが長くても入る |
| 回数や規模ごとの比較（系列 2〜3） | 横向きのグループ棒。縦の棒で系列が 3 つになると数字が重なる |
| 合計の内訳 | 1 本の積み上げ棒。各部分に金額と名前を付ける |
| 2 つの条件の組み合わせの値 | 図にせず、セルを塗った早見表（ひな形の `table.matrix`） |
| 6 行以下の金額の一覧 | 図にせず表 |

## 色

色はひな形のクラスで付け、`fill` や `stroke` に色を直書きしない。

| クラス | 使うところ |
| --- | --- |
| `c-muted` | ふつうの棒 |
| `c-hl` | 図の題が指している 1 本だけ |
| `c-s1`・`c-s2`・`c-s3` | 順序のある系列（少→多、小→大）。薄い→濃い |
| `c-up`・`c-down` | 増減を良し悪しで見せるときだけ |
| `c-text`・`c-sub` | 数字とラベル・凡例と注記 |
| `c-em` | `c-hl` の棒の名前など、強調した部分を指す文字 |
| `c-on-hl` | `c-hl` の棒の上に書く文字。主色に合わせて白か黒になる |
| `c-on-dark` | `c-s3` のような濃い棒の上に書く文字 |
| `c-axis` | 軸の線 |

## 決まり

- 題と条件（いつの、何の値か）は `figure` の `.ftitle`・`.fsub` に書き、SVG には数字・ラベル・凡例だけを入れる。出典は `figcaption`。
- 棒は 0 から描き、値は棒の端に書く。目盛りは付けない。0 の値は幅 1 の棒にして「0 円」と書く。
- 金額は図の中で丸め方をそろえる（例：1 万円未満は 100 円単位、以上は「1.9 万円」）。
- 太字は、本文で触れる数字だけにする。

## 座標の出し方

座標と文字の位置は、Python で出して SVG に写す。

```python
rows = [("項目 A", 520), ("項目 B", 69), ("項目 C", 14)]
x0, w, pitch = 160, 330, 30   # 棒の始まり、最大値の長さ、行の間隔
peak = max(v for _, v in rows)
for i, (label, v) in enumerate(rows):
    y = 9 + i * pitch
    bw = max(v / peak * w, 1)
    print(label, "y", y, "width", round(bw, 1), "value_x", round(x0 + bw + 8, 1))
```

- 文字の幅の目安は、日本語 1 文字が文字サイズと同じ、数字と英字がその 0.6 倍。いちばん長い値の文字が viewBox の右端に収まるよう、最大値の長さ `w` を決める。
- 縦の棒を並べるときは、隣どうしの数字の中心の間隔が、長いほうの数字の幅より広いことを確かめる。
- PDF にしたら、図のあるページを拡大して、数字が棒や隣の数字に触れていないかを見る。

```sh
pdftoppm -f <ページ> -l <ページ> -r 150 -x <左> -y <上> -W <幅> -H <高さ> -png <資料>.pdf <出力の頭>
```
