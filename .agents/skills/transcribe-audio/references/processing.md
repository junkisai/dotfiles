# 文字起こし実行

Apple Silicon では同梱 `scripts/transcribe.sh` と mlx-whisper を使う。必要な ffmpeg / Python パッケージを確認し、不足時は既存環境を壊さない環境へ導入する。対応しない OS なら利用可能な方式を説明し、クラウドへ無断アップロードしない。

共有一時パスは存在するうちに作業ディレクトリへコピーする。既に消失している場合だけ、安定した保存先の音声を求める。

```bash
bash <skill-dir>/scripts/transcribe.sh <audio> <work_dir> [chunk_min] [model]
```

既定は30分チャンク・large-v3-turbo。`clean.txt` は無音時の反復を畳んだ本文、`full.txt` は生結合。同じ音声・設定・作業ディレクトリで再実行すれば済んだチャンクを再利用する。別音声へ作業ディレクトリを流用しない。

長時間処理は環境の継続実行機能を使い、進捗を報告する。品質が不明な音声だけ短い区間で試す。メモリ不足や中断時はログを確認し、必要ならチャンクを短くする。
